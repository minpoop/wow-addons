# Archived portrait source

JamesSunderland.png is the original generated fan-art source used by earlier
ForeverXP development builds. Version 0.5.1 removes the runtime portrait and TGA.
This source is retained only as an unused development reference and is excluded
from the addon package. The current interface uses procedural textures, text and the original navigation arrow described below.


# Original navigation arrow

NavigationArrow.svg is a small original geometric arrow authored for version 0.7.
The packaged Assets/NavigationArrow.tga is an uncompressed 64×64 equivalent drawn
from the same polygon coordinates, with a transparent background. It is a
navigation glyph, not a character portrait or extracted franchise asset.
