# wow-addons

**ForeverXP 2.6.0**: a free leveling guide addon for WoW Forever (Alliance, interface 16001).

The addon lives in [`ForeverXP/`](ForeverXP/). See [`ForeverXP/README.md`](ForeverXP/README.md) for features and the changelog,
and [`ForeverXP/CLAUDE.md`](ForeverXP/CLAUDE.md) for the code layout, step format and the checks to run after changes.

To install, copy the `ForeverXP` folder into `World of Warcraft/_classic_/Interface/AddOns/`.
